# 🚀 TaskFlow - MERN Stack Task Management System

TaskFlow is a dynamic, full-stack Task Management application built using the **MERN** stack (MongoDB, Express.js, React, Node.js). It provides real-time task tracking, project assignment, user management, and team communication features.

## ✨ Features

- 🔑 **Authentication & Authorization:** Secure User Registration, Login using JWT, and Role-Based Access Control (Admin / Project Manager / Developer).
- 📋 **Task Management:** Create, assign, update, and track task statuses (To Do, In Progress, In Review, Done) with Kanban Board and List Views.
- 📁 **Project Organization:** Create and manage projects with team members.
- 💬 **Team Chat Box:** Integrated communication features for team members.
- 📱 **Responsive UI:** Clean and modern interface tailored for Desktop and Mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios, React Router
- **Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose, JWT
- **Deployment:** Vercel (Serverless Architecture)
